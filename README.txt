مبادرة آفاق — نسخة موقع ثابتة جاهزة للنشر على GitHub Pages.

ارفع محتويات هذا المجلد إلى Repository عام، ثم فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > / (root).
بعد ظهور رابط الموقع، يمكن تحديث sitemap.xml وrobots.txt بالرابط النهائي ثم إضافة الموقع إلى Google Search Console.
